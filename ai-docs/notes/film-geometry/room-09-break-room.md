# Room 9, Break room: film structure sheet

Study date 2026-11-15. Source: the film NEXUS: HANK RAID, frames pulled at 2 per second for 9:20 to 11:15 (the brief's 9:40 to 10:30 widened by 20 s each side), contact sheets at 1 per second, and the build zu renders (game camera and film camera).

A grunt is taken as 1.8 m; "h" is one character height. Across-room positions run 0 (left wall) to 1 (right wall) as the camera sees the room. Sizes come from stills in loose perspective; treat metres as plus or minus 20 percent.

## Which film set this room follows

The brief's span 9:40 to 10:30 holds three sets, not one:

- **Set B, the poster room, 9:38.0 to 10:00.5 (22 s).** A dim red room with barrels, a table, a hose on the wall, joke posters ("stop putting posters on this wall", a missions to-do list, "agents don't do law"), a closed back door with a hazard-striped foot, a dark doorway with a hazard header at the right. Before it is the garage (room 6's set, to 9:37.5).
- **10:01 to 10:13.5: the locker room** (lockers, a wanted poster, a floor that slopes up to the right). That is room 8's set, not this one.
- **Set A, the canteen, 10:14.0 to 10:33.5 (19 s).** A serving counter with a menu board (booze, chili dog, coffee), cups, a "cheapest booze" sign, a round red light, a doorway in the back wall, a raised walkway along the back wall. After it is the admin room (room 10's set, from 10:34).

The room follows **set A, the canteen**: it is the only set that is plainly a break room (food counter, menu, drinks), which is what the README room is. Set B is on screen 3 s longer, so by the brief's "longest" rule it would win; none of the owner's screenshots show either set. Set A is chosen for identity; set B's barrels, table and posters can dress the same room. Both match the README's idea (a break room, false calm turning into a fight).
