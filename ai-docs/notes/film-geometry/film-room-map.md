# Where each room is in the film

The film is NEXUS: HANK RAID (https://www.youtube.com/watch?v=v0suvMY3GgM). It cuts between short fights drawn by different animators, so one map room can match several film sets, and the README's first film times were guesses that turned out wrong for several rooms. This table is the reference: check a room here before reading, building or judging it against the film, and correct this table first when a study finds otherwise.

Read from frames at 2 per second (2026-11-15 studies). Times are m:ss into the film. "Follows" is the set the room's structure sheet is built from; the others are listed so nobody mistakes them for the room.
